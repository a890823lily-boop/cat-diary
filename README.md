# 貓咪日記 cat-diary

### 👉 [開啟 App：a890823lily-boop.github.io/cat-diary](https://a890823lily-boop.github.io/cat-diary/)

記錄貓咪照片與日常的手機 App。用 iPhone Safari 開啟後，點「分享」→「加入主畫面」就能像 App 一樣使用，沒有網路也能開。

使用純 HTML、CSS、JavaScript 製作，不需安裝任何套件。

## 功能

- **多隻貓咪**：每隻貓有大頭照、生日（自動算年齡）、性別、品種花色
- **日記**：日期時間、類別（日常、飲食、便便、玩耍、睡覺、健康、看醫生、洗澡美容、其他）、記事、多張照片
- **相簿**：所有照片依月份排列，點開看大圖，可左右滑動切換
- **篩選**：有兩隻以上貓咪時，上方可切換只看某一隻
- **今日貓咪**：日記頁最上方每次打開都隨機顯示一張貓咪照片（內建照片＋日記裡的照片），點照片或「換一張」就會換
- **小日曆**：日記頁的月曆，每天顯示日記照片、心情、內耗球記號；點某天可看當天紀錄，並補寫那天的日記
- **抽一句鼓勵**：日記頁最上方先選今天的心情（開心、好累、難過、焦慮、生氣、孤單、普通），再抽適合的鼓勵小語；可以一直抽，全部抽過一輪才會重複
- **塗色貓咪**：「玩樂」分頁有 4 張貓咪線稿，點一下區塊就塗滿顏色，可復原、清除、存成圖片或存到日記；心情不好時，鼓勵卡片會建議去塗色
- **內耗球**：把內耗的事打出來變成一顆顆球掉進罐子（可拖曳甩動），會自動偵測心情（焦慮、難過、生氣、疲累、孤單、自責、迷惘）決定球的顏色，點球可跟貓咪聊聊（內建回覆，不是 AI）或戳破放下；提到想傷害自己時會提供 1925 等求助專線
- **呼吸練習**：跟著貓咪肚子起伏吸氣 4 秒、停 2 秒、吐氣 6 秒，可選 1／3／5 分鐘，可開呼嚕聲
- **擼貓模式**：手指摸貓咪，開心度上升、瞇眼、臉紅、甩尾巴、呼嚕聲變大（一直摸肚子會生氣）
- **貓咪圖鑑**：寫日記、抽鼓勵、塗色、呼吸、擼貓、抽運勢、玩遊戲等會收集 12 張貓咪貼紙（在「貓咪」分頁），集滿頒發「貓咪圖鑑大師」證書並解鎖隱藏塗色圖「👑 皇冠貓」
- **今日貓咪運勢**：「玩樂」分頁每天抽一支貓咪籤（大吉～小凶，還有稀有的喵吉），附宜忌、幸運色、幸運物
- **小遊戲「貓咪翻翻樂」**：翻牌配對，優先用日記裡的貓咪照片當卡片，分簡單／普通／困難，記錄最佳步數與時間
- **小遊戲「貓咪接魚乾」**：限時 60 秒，左右拖曳溜冰貓，接住 🐟（+1）和 🍤（+3），碰到 🥒 會被嚇到少一條命，會記錄最高分
- **背景音樂**：右上角 🎵 可選貓咪音樂盒、晚安搖籃曲、雨聲、貓咪呼嚕聲，全部由程式即時合成（原創旋律、沒有音樂檔）
- **備份**：匯出／匯入 JSON 備份檔（含照片），換手機或清除瀏覽器資料前請先備份
- 支援深色模式

## 資料存在哪裡？

所有照片和日記都存在**你自己裝置的瀏覽器**（IndexedDB）裡，不會上傳到任何伺服器，其他人看不到。
照片會自動縮小到最長邊 1600px 以節省空間。

> 注意：刪除 App、清除 Safari 網站資料，資料就會消失，請定期到「貓咪」分頁匯出備份。

## 插圖來源

裝飾用的溜冰貓、西裝貓、薩克斯風貓、坐魚貓、魔法師貓插圖來自 [いらすとや（Irasutoya）](https://www.irasutoya.com/)。

## 本機測試

```
python3 -m http.server
```

再開啟 http://localhost:8000 。

修改網站內容後，請把 `sw.js` 裡的 `VERSION` 加一，並把 `index.html` 裡 css、js 網址後面的 `?v=` 改成同一個數字。這樣已安裝的 App 才會更新，而且不會混到舊版檔案。

## 檔案結構

```
index.html            頁面與對話框
css/style.css         樣式（手機優先、深色模式）
js/quotes.js          抽一句鼓勵的小語（想加句子就改這裡）
js/game.js            小遊戲「貓咪接魚乾」
js/memory.js          小遊戲「貓咪翻翻樂」
js/coloring.js        塗色貓咪（線稿、調色盤）
js/fortune.js         今日貓咪運勢（籤的內容在這裡）
js/relax.js           呼吸練習、擼貓模式
js/worry.js           內耗球、喵喵聊天室
js/worry-talk.js      喵喵聊天室的回覆內容（想改貓咪說的話就改這裡）
js/stickers.js        貓咪圖鑑（貼紙清單與取得條件）
js/music.js           背景音樂（Web Audio 即時合成）
js/db.js              IndexedDB 資料庫（貓咪、日記、照片）
js/app.js             畫面、表單、照片處理、小日曆、備份
manifest.webmanifest  App 名稱、圖示、主題色
sw.js                 Service Worker（離線快取）
icons/                App 圖示（用自家貓咪的照片）
images/               自家貓咪照片（歡迎頁、空白頁面用）與裝飾插圖
```
